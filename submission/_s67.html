07The loop

The model chooses the move.
Code decides what is legal.

判断はモデル、禁止事項はコード。プロンプトで破れない場所にガードを置いています。
1 · No source, no input
DROP THE ACTION
Every fill or select must carry from, naming the record it came from. Unsourced values never reach the browser.
2 · Nothing left behind
SUBMIT BLOCKED
Each document field must be entered, or declared “not applicable” with a reason. The unresolved set must be empty before the final button exists.
3 · The last button is human
ASK FIRST
A submit action, or any click whose label looks like a final application, triggers a read-back and waits for an explicit “yes”.
4 · Bounded by construction
STOP GRACEFULLY
30 turns, 3 questions, 10 minutes of waiting. On any breach the sandbox is destroyed and the run is reported as failed — never as done.
